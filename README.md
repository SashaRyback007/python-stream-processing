# Лабораторна робота №3: Ітератори, генератори та потокова обробка даних

## Варіант 2. Потокова обробка системи обліку книг

### 1. Мета роботи
Сформувати практичні навички роботи з ітераційною моделлю Python, ітераторами, генераторами (`yield`, `yield from`), виразами-генераторами (*generator expressions*), модулем `itertools`, принципом відкладених обчислень (*lazy evaluation*) та побудовою конвеєрів потокової обробки великих наборів даних без завантаження їх у пам'ять.

---

### 2. Структура проєкту
Проєкт організовано у вигляді модульного пакета відповідно до рекомендацій методичних вказівок:

```text
stream_project/
├── pyproject.toml              # Метадані та конфігурація проєкту
├── README.md                   # Документація лабораторної роботи
├── data/
│   └── books.csv               # Згенерований вхідний набір даних
└── src/
    └── stream_processor/
        ├── __init__.py         # Ініціалізація пакета
        ├── models.py           # Модель BookRecord та власний клас-ітератор
        ├── readers.py          # Потокове читання файлу через yield from
        ├── parsers.py          # Потоковий парсинг рядків CSV у словники
        ├── filters.py          # Валідація даних та фільтрація за автором/роком
        ├── transformations.py  # Ледача нормалізація текстових полів
        ├── batches.py          # Пакетна обробка через itertools.islice
        ├── analytics.py        # Потокова агрегація та пошук з Early Termination
        ├── pipeline.py         # Складання стадій конвеєра
        ├── generator_data.py   # Генератор синтетичного набору даних
        └── main.py             # Точка входу: демонстрація пайплайну та бенчмарк

3. Схема потокового конвеєра (Streaming Pipeline)
Обробка даних відбувається строго поелементно без створення проміжних матеріалізованих колекцій:

Plaintext
books.csv
   │
   ▼
read_lines()                 [readers.py]          - Потокове читання через yield from
   │
   ▼
parse_csv_rows()             [parsers.py]          - DictReader + yield from
   │
   ▼
validate_books()             [filters.py]          - Пропуск некоректних записів
   │
   ▼
normalize_book_titles()      [transformations.py]  - Приведення заголовків/авторів
   │
   ▼
filter_by_author_and_year()  [filters.py]          - Фільтрація за критеріями
   │
   ├──────────────────────────────┬──────────────────────────────┐
   ▼                              ▼                              ▼
batched_books()         calculate_streaming_stats()     find_first_book()
[batches.py]            [analytics.py]                  [analytics.py]
Пакетна обробка         Потокова агрегація              Early Termination

Інструкція із запуску
Склонуйте репозиторій або відкрийте кореневу папку проєкту.

Переконайтеся, що встановлено Python версії 3.10 або новішої.

Запустіть головний модуль конвеєра:
python src/stream_processor/main.py
